關於 OmniAI

OmniAI 是由集聯科技有限公司營運的企業級 AI API 整合平台，透過單一 API 提供模型存取、流量路由、API 金鑰、權限、用量與成本管理。

我們的使命

協助台灣團隊以更簡單、可控且透明的方式導入 AI。開發者可使用熟悉的 API 介面串接模型，管理者則能集中掌握權限、額度、用量與費用。

目前提供的服務

  • OpenAI 相容及平台標示支援的 API 介面
  • 多模型與上游渠道路由
  • API 金鑰、群組、額度與存取權限管理
  • 用量、費用、請求狀態與效能統計
  • 預付額度、人工匯款與平台顯示的其他付款方式

實際可用模型、功能及價格以 OmniAI 模型廣場與控制台當下顯示為準。

服務原則

  • 透明：清楚呈現模型價格、用量與額度消耗。
  • 可控：提供金鑰、群組、權限及使用限制，降低導入風險。
  • 相容：採用常見 API 介面，降低既有應用程式的遷移成本。
  • 在地：由台灣公司營運，提供繁體中文服務與台灣時區支援。

企業合作

OmniAI 可配合概念驗證、團隊試用、額度管理及企業導入需求。建議先使用非機密、低風險資料進行驗證，再依組織的資安與法遵流程逐步擴大使用。
