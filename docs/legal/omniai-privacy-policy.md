# OmniAI 隱私政策

生效日期：2026 年 8 月 19 日

本隱私政策說明集聯科技有限公司（以下稱「本公司」）如何透過 OmniAI 服務收集、使用、保存及保護您的個人資料。

## 1. 我們收集的資訊

我們可能收集下列資訊：

- 帳號資料：使用者名稱、電子郵件地址（如有提供或綁定）、顯示名稱及驗證狀態。
- 付款與帳務資料：儲值金額、交易編號、付款方式、訂單狀態及您為付款或退款提供的必要資料。完整信用卡資料由第三方付款服務商處理，本公司不儲存完整卡號。
- API 使用資料：API 金鑰識別資訊、模型名稱、Token 或其他計費用量、請求時間、回應狀態、延遲、錯誤資訊及所屬帳號或群組。
- 安全與技術資料：登入與管理操作的 IP 位址、瀏覽器及裝置資訊、Session 資訊、系統與稽核紀錄。
- 您主動提供的資料：客服、退款、帳務或企業合作往來中提供的內容。

若您不提供建立帳號、付款或履行服務所必要的資料，部分功能可能無法使用。

## 2. Prompt、模型輸入與輸出

OmniAI 會在履行 API 請求所必要的範圍內，將您提交的 Prompt、訊息、檔案或其他輸入轉送至所選模型的上游供應商，並將模型輸出回傳給您。

本公司不以您的 Prompt 或模型輸出訓練自有模型，也不會出售這些內容。為提供服務、偵測濫用、排除錯誤、計費、處理爭議或遵守法律，系統可能暫時處理或於必要範圍內保留有限的請求內容、錯誤片段或安全紀錄。請勿透過本服務提交不必要的敏感個人資料、機密資料或您無權處理的內容。

上游 AI 供應商可能依其自身條款與隱私政策保存或使用輸入及輸出。選用模型前，請自行確認該供應商的資料政策是否符合您的需求。

## 3. 我們如何使用資訊

我們使用相關資訊以：

- 建立及管理帳號、API 金鑰與存取權限；
- 路由 API 請求並提供模型服務；
- 計算用量、扣除額度、處理付款、退款及帳務對帳；
- 維護服務安全、偵測詐欺、濫用、異常流量及未授權存取；
- 提供客服、事故通知、服務更新及帳務通知；
- 分析並改善服務品質、可靠性及效能；
- 執行服務條款並遵守中華民國（台灣）個人資料保護法及其他適用法律。

## 4. 資料共享與跨境傳輸

我們不出售您的個人資料。我們僅在必要範圍內與下列對象共享資料：

1. 上游 AI 模型或 API 供應商，用於履行您指定的請求；
2. 付款、銀行或帳務服務商，用於處理交易與退款；
3. 雲端、網路、資安、郵件及客服服務商，用於營運 OmniAI；
4. 專業顧問、主管機關或執法機關，在法律要求或保護合法權益時。

部分上游供應商或服務商位於台灣以外地區，因此資料可能發生跨境傳輸。跨境處理將限於提供服務所需的合理範圍。

## 5. 資料保留

帳號、交易、用量及稽核資料會依提供服務、帳務對帳、安全調查、爭議處理及法令要求所需的期間保存。當資料不再需要時，我們會刪除、匿名化或以其他適當方式處理。

帳號刪除前如仍有未使用餘額，請先依《OmniAI 服務條款》的退款規定提出申請。依法或因爭議、資安事件、付款紀錄與會計憑證需要保存的資料，可能在帳號刪除後繼續保留必要期間。

## 6. Cookie 與本機儲存

OmniAI 使用登入 Session、語言、主題及其他服務運作所必要的 Cookie 或瀏覽器儲存。若啟用網站分析工具，我們會依適用法律與網站介面所提供的選項取得同意。您可透過瀏覽器設定清除 Cookie，但可能因此需要重新登入或無法使用部分功能。

## 7. 資訊安全

我們採取合理的技術與組織措施保護資料，包括傳輸加密、權限控管、操作稽核、密鑰與憑證管理、備份及安全監控。然而，任何網路服務均無法保證絕對安全；請妥善保管密碼及 API 金鑰，並在懷疑外洩時立即撤銷或更換。

若發生可能影響您權益的個人資料事件，我們將依適用法律評估並通知受影響者及主管機關。

## 8. 您的權利

依台灣個人資料保護法，您得就本公司保有的個人資料請求查詢或閱覽、製給複製本、補充或更正、停止蒐集處理利用，或請求刪除；法律另有規定者除外。

請使用您的帳號識別資料聯絡 OmniAI 服務窗口：support@bazaarlink.ai。我們可能要求合理的身分驗證，以避免資料遭未授權存取。

## 9. 未成年人

OmniAI 原則上僅供年滿 18 歲者使用。未滿 18 歲者應由法定代理人同意並在其監督下使用。本公司不會在明知的情況下向未滿 13 歲兒童提供帳號服務。

## 10. 第三方網站與服務

OmniAI 可能連結或整合第三方網站、模型及服務。第三方的資料處理行為適用其自身條款與隱私政策，本公司無法控制其全部作業。

## 11. 政策變更

我們可能因服務、法令或營運需求更新本政策。重大變更將於生效前透過網站公告、電子郵件或其他合理方式通知。您在變更生效後繼續使用 OmniAI，即表示您已閱讀更新內容。
